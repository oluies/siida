# modules/pkg

The Alpenhorn-style Private Key Generator (PKG) and friend-discovery
primitives. Issues identity-based decryption keys to clients and runs
the lookups that bootstrap private communication between users who do
not yet share a key.

This module is a **placeholder** until spec
[`005-pkg-keybootstrap`](../../specs/005-pkg-keybootstrap/spec.md)
lands. That spec ports the Alpenhorn key-generator and friend-
discovery code into the JVM-native build.

Do not edit the `Placeholder` here in unrelated PRs.

# modules/agent

The agent-messaging layer: APIs, schemas, and conventions for
autonomous AI agents to exchange private messages over Siida. Builds
on the client SDK and is the primary differentiator of Siida from
upstream Vuvuzela.

This module is a **placeholder** until spec
[`008-agent-messaging`](../../specs/008-agent-messaging/spec.md)
lands. Offline-agent semantics may push some scope into the async
delivery layer ([009](../../specs/009-async-delivery-over-mixnet/spec.md)).

Do not edit the `Placeholder` here in unrelated PRs.
